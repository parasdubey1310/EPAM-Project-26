# XYZ Bank Customer Coupon Portal

A simple JavaScript-based web application developed as part of the **EPAM Project Development Program - Week 1 Assignment**.

## Project Overview

This application simulates a customer portal for XYZ Bank where users can:

- Register for the customer portal
- Validate their Customer ID
- Generate a Diwali Coupon
- Experience interactive JavaScript events

---

## Features

- ✅ Welcome message on mouse hover
- ✅ Register button functionality
- ✅ Customer ID validation
- ✅ Coupon generation
- ✅ Dynamic message display using JavaScript
- ✅ Simple and responsive user interface

---

## Technologies Used

- HTML5
- JavaScript (ES6)

##  How to Run

1. Download or clone the repository.
2. Open the project in Visual Studio Code.
3. Open `index.html` using Live Server.
4. Enter a Customer ID containing **XYZ**.
5. Validate the Customer ID.
6. Generate your coupon.
